# Security policy

Seacommons handles potentially sensitive humanitarian and location data. Do not
report vulnerabilities in a public issue. Contact the maintainers through the
private security reporting channel configured on the repository.

Supported security fixes target the latest release. Production deployments must
enable OIDC, TLS, webhook signature verification, encrypted backups and a tested
retention policy. Public deployments must not expose live personal locations or
unverified distress reports.

The platform is a research prototype and is not certified for emergency dispatch
or as a substitute for official maritime rescue coordination channels.
